# Git repo

**For LLM:** Use when syncing work to a git remote.

- Commit and push the branch already checked out: `main` when you are on `main`, the feature branch when you are on that. Do not switch branches or retarget the push.
- Review what is staged before committing and include only the changes related to this work. Leave unrelated edits, local scratch files, and anything ignored out of the commit.
- Do not add a GitHub Actions workflow, hook, or other automation. Write the commit message and sync.
